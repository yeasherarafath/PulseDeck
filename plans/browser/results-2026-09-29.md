## BUG-01 (found & fixed)

Per-service `notify_on_failure/recovery` switches never persisted (all saved `false`):
`StatusServiceRequest::rules()` lacked the fields so `validated()` stripped them before
`normalizeServiceAttributes()`. Fixed in `app/Http/Requests/Status/StatusServiceRequest.php`
(rules + normalize list), Pint clean, proven via UI save on Main Website + Broken API,
create-path defaults verified ON for Drill Service. Committed `d0ca4f5` (tests green).

test jobs. 2303 ran stale code → `service.recovered` mail failed with
“undefined function branding_asset()” and likely caused the transient heartbeat NULLs.
Both killed per user approval (serve :8001 kept). All queue work now via exclusive
`--once/--stop-when-empty` runs. Heartbeat verified “Running” since.
