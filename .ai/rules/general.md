# General

## Conventional Commits message format
Write every commit message as `<type>(<scope>): <short description>` (e.g. `feat(status): add push monitors`, `fix(public): correct last-updated time`). Use types feat, fix, docs, refactor, test, chore; scope is the area touched; description is imperative, lowercase, no trailing period.
